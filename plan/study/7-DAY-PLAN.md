# The 7-Day Plan

Hour-by-hour, interleaving building and studying. Assumes full days available.

**The split: ~15 hours building, ~45 hours studying.** Building is front-loaded so that by
Day 3 you're purely practising.

> **The one rule that overrides everything below:** if at any point a stage is 🔴 and you're
> choosing between building a feature and drilling that stage — **drill.** The app is a means.
> The [fast path](#the-fast-path-if-you-fall-behind) tells you exactly what to keep.

## The fast path (if you fall behind)

Cut in this order. Each line is a decision you can make on any morning:

1. **Phase 07** — never build it
2. **Listening + Reading modules** (Phase 05 steps 5.3, 5.4) — use public resources instead
3. **Motion + Switch games** — watch the videos, don't build them
4. **Phase 04 entirely** — watch all the game videos, play once on any public practice site
5. **Phase 05 essay grading** — write essays in a plain text file, self-assess against the rubric

**The irreducible core: Phases 00, 01, 02, 03, 06.** That's roughly 14 hours of building and it
covers: AI Literacy, technical MCQ, pseudocode, debugging, AI-assisted coding, mocks, and the
readiness dashboard. Five of the six stages, including both eliminatory ones nobody prepares for
and the one that sets your salary.

If you have **only one day to build**: Phase 00 + Phase 01, generate the AI Literacy and
pseudocode banks, and drill. That is a genuinely good week of preparation on its own.

## Exam-day checklist

**The night before**
- [ ] Sleep 8 hours. Non-negotiable — the cognitive games measure exactly what sleep deprivation destroys.
- [ ] Laptop charged, charger packed
- [ ] Browser tested (Chrome), camera and mic verified
- [ ] Internet checked; backup hotspot ready
- [ ] ID, Aadhaar, DigiLocker access confirmed
- [ ] Login credentials tested, not just saved

**The morning of**
- [ ] Eat. Low blood sugar wrecks working memory, which is a quarter of the exam.
- [ ] Re-read your one-page revision sheet — once, not five times
- [ ] Re-read the 5-step AIC protocol and the 4-step debugging method
- [ ] Quiet room, door shut, phone off, desk clear

**During**
- [ ] **Read every section's instructions before starting it.** Every time.
- [ ] Never leave a blank — no negative marking is reported
- [ ] Flag and move on; don't over-dwell. Over-dwelling kills more candidates than not knowing.
- [ ] Debugging: read the spec, hypothesise the family, *then* edit
- [ ] AI-assisted coding: Frame → Plan → Prompt → **Review** → Refine. Do not skip Review.
- [ ] Games: read the rules, then start. Push depth, don't farm easy levels.
- [ ] Behavioural: answer honestly and consistently. Don't construct a character.
